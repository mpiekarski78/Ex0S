# Neural-memory boundary

**Product 0.0.004.** Ownership law for TM.0.44.MEMPROJ. Not a capability claim.

S may remain external storage. It must be semantically ignorant: opaque neural projections and provenance only.

| Component | May own | Must not own |
| --- | --- | --- |
| Cortex | learned projections, attention, write/read decisions, action policy | fixture answers or task-specific routes |
| S | opaque vectors, timestamps, provenance, generic retrieval operations | relations, cue meanings, answer handles, paths, task types |
| ρ | transient recurrent activity | persistent facts |
| Runner | events and behavioral scoring | retrieval addresses or internal corrective actions |
| SOCP organ | current weights and internally credited constraints | symbols, expected outputs, future probes |

Opaque rows are `{key, value, when, provenance_id}`. `when` and `provenance_id` are audit-only and excluded from retrieval.

The runner calls one public organism path. It must not compute \(q\), call nearest neighbor, reinstate \(v\), or select a record.
