# Ex0S lineage

**Ex0S** — acquired state lives outside cognitive weights.

Pronounce “ex-oh-ess” (or “exos”). The **0** marks the claim: world knowledge is **not** stored in cortex / policy weights.

Public repo: [mpiekarski78/Ex0S](https://github.com/mpiekarski78/Ex0S).

## What it is

A developmental organism lineage:

- **Genome / cortex / recipe** — frozen species prior + boxed learning procedures  
- **S** — inspectable acquired state (notes you can open)  
- **ρ** — disposable working trace  
- **P** — how to search / match / compare / compose — not facts  
- **W** — unread library until committed  

The scientific win condition is not a bigger model. It is:

> world diversity ↑ · S / experience ↑ · genome delta ≈ 0
